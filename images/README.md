# Папка для скриншотов курса

Сюда нужно положить скриншоты из 1С для курса онбординга.

## Формат именования

Используй понятные имена на латинице:
- `1c-interest-create.png` — создание интереса
- `1c-order-form.png` — форма заказа клиента
- `1c-partner-card.png` — карточка партнёра
- `1c-payment-check.png` — проверка оплаты

## Как делать скриншоты

### macOS
- `Cmd + Shift + 4` — выделить область
- Файл сохранится на рабочий стол

### Windows
- `Win + Shift + S` — выделить область
- Вставить в Paint и сохранить
